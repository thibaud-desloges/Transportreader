# TransportReader

Application iPhone de lecture de cartes de transport : fonctions Navigo existantes et première lecture expérimentale ZOU!.

Ouvrir `TransportReader.xcodeproj` dans Xcode et choisir le schéma **TransportReader**.

Basée sur [PassReader de CelianF](https://github.com/CelianF/metroreader), issu de [DocSystem/metroreader](https://github.com/DocSystem/metroreader). Les crédits des auteurs sont conservés dans l’app. Le TestFlight du projet d’origine ne distribue pas cette version locale.

Voir [ZOU-INTEGRATION.md](ZOU-INTEGRATION.md) pour les limites et le protocole du premier test ZOU!.
